# Benchmark Results (python 3.12.3)

This file contains the benchmark results across various Python runtime type validation packages.

Generated by `/utils/benchmark.py`

### Benchmark Methodology
- Every type checker is tested with the exact same data and test cases.
- The reported time represents the average duration of a single validation (one function call), measured over 100 runs (ignoring the initial warmup run).
- Timings with warning symbols (⚠) indicate that the checker did not catch invalid data inside collections (e.g. invalid items placed outside a sampled subset).
